# Paradise Moms - Product Overview

Paradise Moms is an e-commerce platform specializing in natural and organic products. The application provides a complete shopping experience with user authentication, product browsing, shopping cart functionality, and order management.

## Key Features
- User authentication with Google Sign-In
- Product catalog with filtering and search
- Shopping cart with persistent state
- Checkout and order processing
- Admin panel for product and order management
- Responsive design optimized for all devices

## Target Users
- Customers seeking natural and organic products
- Admin users managing inventory and orders

## Business Logic
- Products are organized by categories with ratings and reviews
- Cart state persists across sessions using localStorage
- Orders are processed through a GraphQL backend
- User profiles track order history and preferences
